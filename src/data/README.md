# src/data

Static seed data for the Opportunity Discovery Engine
(see `docs/plans/opportunity-discovery-engine.md` §7). Loaded into Postgres by
`scripts/seed-opportunity-data.ts` (`npx tsx scripts/seed-opportunity-data.ts`).

## nonstop-routes.json

Generated by `scripts/build-nonstop-routes.mjs` from the
[OpenFlights](https://github.com/jpatokal/openflights) `routes.dat` and
`airports.dat` files (Open Database License). Filtered to nonstop (`stops == 0`)
routes departing a US airport and arriving in the US, Canada, Mexico, or the
Caribbean (plus Bermuda), aggregated by `(originIata, destIata)` with the unique
set of IATA airline codes. `typicalDurationMins` is an estimate from
great-circle distance (800 km/h cruise + 40 min overhead), not a schedule.

OpenFlights route data was last updated in 2014, so carriers and pairs are
stale (defunct codes such as `US`, `FL`, `VX` appear). It seeds candidate
generation only; rows carry `source: "OPENFLIGHTS_SEED"` and are superseded as
`OBSERVED_OFFER` upserts arrive from the flights provider layer.

## destination-profiles.json

Hand-authored (`generatedBy: "HAND_AUTHORED_2026_09"`) profiles for 42 US
leisure destinations and 10 Mexico/Caribbean destinations. Coordinates match
`src/lib/airports.ts`. Tier, trip length, walkability, parking, family fit and
anchors are editorial judgments. `climate.monthly` values are approximate
1991-2020 normals (F / precipitation days) from memory of published station
data; they are historical context for stage-1 checks, not a forecast, and
should be treated as +/- a few degrees.
